# Rules we hold

The five rules that hold in every Noventia product at every stage, and the rule for transactions a user starts.

Published at https://noventia.xyz/docs/rules-we-hold. Updated 2026-11-15.

These five rules hold in every Noventia product, at every stage. Each one links to the page that explains it.

## Facts

**Facts only with a transaction behind them.**

A fact is something that happened, recorded with the transaction that proves it. Anyone can open that transaction in an explorer such as Solscan. If a fact cannot be proven by a transaction, it is not on a passport or a card. See [Facts and proofs](facts-and-proofs.md).

## Score

**No single score.**

A passport has branches: Holder, Trader and Builder. Each branch has its own EP and a level from L1 to L5. Nothing adds them up into a total. See [Branches](branches.md).

## Privacy

**Private by default.**

Every branch is private until its owner opens it. Others see only the Noventia ID and the branches the owner opened. Permissions for others to read a private branch are planned for stage 2, Economy. See [Permissions](https://noventia.xyz/docs/permissions).

## Appeals

**Every freeze has an appeal.**

A wallet is frozen when a project's list check finds it among linked wallets: wallets of at least 3 owners that two or more independent signals link. It earns no new points in any branch until a review is decided. Only that wallet is frozen. A person's own wallets do not count against each other, and a shared funder alone is not enough. A wallet that looks automated earns no Trader EP until an appeal is decided.

To appeal, use the Appeal button on the passport, or email [support@noventia.app](mailto:support@noventia.app) with the Noventia ID. Noventia decides each appeal. See [Cases and the council](cases-and-council.md).

## Funds

**Noventia does not hold funds.**

Noventia has no access to user funds. See [Security](https://noventia.xyz/security).

## Transactions you start

For actions you start, such as SOL reclaim and swaps, one rule holds:

A transaction reaches your wallet only after an action you started, and you confirm it there. Any Noventia fee is shown before you sign.

SOL reclaim, closing empty token accounts to return their rent, and swaps are live in the app at https://app.noventia.app. Each is a transaction you start there and sign in your own wallet.

If something asks you to approve a transaction in Noventia's name that you did not start, it is not Noventia.

## No connect wallet on this site

This site, noventia.xyz, has no "connect wallet" button and loads no scripts from other sites. The passport runs at [app.noventia.app](https://app.noventia.app).
